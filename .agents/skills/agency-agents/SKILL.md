# The Agency - 268 Specialized AI Agents

**The Agency** (by Michael Sitarzewski) provides 268 expert AI personas across 18 specialized divisions. All 268 agents are installed globally as Antigravity skills with the `agency-` prefix, allowing you to invoke any specialist instantly.

## How to Activate an Agent Persona

You can activate any specialist in natural conversation:
- *"Activate agency-frontend-developer to review our Next.js component hierarchy."*
- *"Use agency-software-architect to design the database schema."*
- *"Activate agency-security-specialist to audit our API endpoints."*
- *"Have agency-code-reviewer review our latest changes."*
